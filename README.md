# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/9368de07-c502-4220-a3ed-00f29aacb45b

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Copy `.env.example` to `.env` and fill it in — ver `docs/despliegue.md`
3. Run the app:
   `npm run dev`
